## 2. 프로젝트 개요

### 프로젝트명

**CulturePick**

### 프로젝트 소개

CulturePick은 전시·공연·문화행사를 탐색하고, 사용자의 취향과 활동 데이터를 바탕으로 문화 콘텐츠를 추천하는 서비스입니다.

외부 공개 API로 수집한 문화 정보를 검색어·분야·지역·기간·무료 여부에 따라 찾아볼 수 있습니다. 사용자는 관심 있는 콘텐츠를 찜하고 리뷰와 평점을 남기며, 마이페이지에서 프로필·취향·최근 본 콘텐츠·이용 및 결제 내역을 관리할 수 있습니다.

### 프로젝트 필요성 및 배경

- **여러 곳에 흩어진 문화 정보:** 전시·공연·문화행사 정보를 제공처마다 따로 확인해야 해 일정과 지역, 관심 분야에 맞는 콘텐츠를 찾는 데 시간이 걸립니다.
- **개인의 취향을 반영한 탐색 필요:** 같은 목록을 보더라도 사용자가 선호하는 분야와 관심사는 다릅니다. 검색 조건과 함께 개인의 취향을 반영하면 문화생활을 선택하는 데 도움이 됩니다.
- **문화 활동 기록의 활용:** 관심을 보인 콘텐츠와 찜·리뷰 등의 활동을 모으면 자신의 취향을 돌아보고, 다음에 즐길 문화를 발견하는 데 활용할 수 있습니다.

### 프로젝트 목표

1. **문화 정보 탐색 편의성 향상:** 전시·공연·문화행사 정보를 한곳에 모으고 검색과 필터를 제공해 원하는 콘텐츠를 쉽게 찾도록 합니다.
2. **사용자 취향에 맞는 콘텐츠 추천:** 초기 취향 설문과 조회·클릭·찜 등의 활동 데이터를 활용해 개인에게 어울리는 문화 콘텐츠와 추천 이유를 제공합니다.
3. **개인의 문화생활 기록과 관리 지원:** 프로필, 관심 콘텐츠, 리뷰, 최근 조회, 이용 및 결제 내역을 마이페이지에서 관리할 수 있도록 합니다.
4. **문화 콘텐츠 탐색과 이용의 연결:** 팀에서 확정한 판매·예약·환불 정책에 따라 예약과 PortOne V2 결제를 연결해 콘텐츠 발견부터 이용 내역 확인까지 이어지는 흐름을 구축합니다.
