## 2. 프로젝트 개요

### 2.1 프로젝트명

**Oddinary**

평범한 일상 속에서 작은 취미와 새로운 문화 경험을 발견하고, 자신만의 취향을 만들어가는 문화 콘텐츠 추천 플랫폼

### 2.2 프로젝트 소개

Oddinary는 외부 공개 API로 전시·공연·문화행사 정보를 수집하고, 사용자 취향에 맞는 문화 콘텐츠를 추천하는 데이터 기반 서비스
초기에는 취향 설문을 바탕으로 콘텐츠를 추천하고 이후에는 검색·조회·찜·리뷰 등 축적된 사용자 행동 데이터를 분석해 인스타그램이나 유튜브처럼 개인의 관심사에 맞는 콘텐츠를 지속적으로 추천

### 2.3 프로젝트 필요성 및 배경

1. 문화 콘텐츠 데이터 통합
- 여러 기관에 분산된 전시·공연·문화행사 데이터를 수집하고 통합 관리할 필요가 있음

2. 데이터 수집 및 관리 자동화
- 데이터 수집·정제·저장 과정을 자동화하여 최신성과 정확성을 유지할 필요가 있음

3. 사용자 맞춤형 추천의 필요성
- 초기 취향 설문과 검색·조회·찜·리뷰 등의 행동 데이터를 활용해 사용자별 관심사에 맞는 추천이 필요함

### 2.4 프로젝트 목표

1. 데이터 수집 및 파이프라인 구축
- 외부 공개 API 데이터 수집·정제·통합 및 ETL 파이프라인 자동화

2. 사용자 행동 데이터 수집 및 분석
- 설문·검색·조회·찜·리뷰 등의 데이터를 저장하고 사용자 취향과 관심사 분석

3. 개인화 추천 시스템 구현
- 초기에는 설문 기반으로 추천하고, 이후에는 축적된 행동 데이터를 기반으로 추천 결과를 개인화

4. 데이터 관리 및 성능 최적화
- 데이터베이스를 구축하고 데이터 처리·조회 성능 및 안정성 검증
